I build products end to end — React/TypeScript front ends, Postgres/Supabase back ends, and the
AI plumbing in between. My recent work is mostly **agent tooling**: local model bridges, MCP
servers, and automation that keeps working against real data instead of demos.

### Featured work

| Project | What it is |
|---|---|
| **[omnirush-hermes](https://github.com/KapilXSam/omnirush-hermes)** | Zero-dependency local proxy that puts OmniRush's GPT-6 models behind a standard OpenAI endpoint — full protocol translation (streaming, tool calls, reasoning), no runtime deps, all secrets kept local |
| **[med-summit](https://github.com/KapilXSam/med-summit)** | Conference platform for pharma/medical events — React 19, TanStack Start, Supabase, Firecrawl ingestion |
| **[Pharmalix-AI-2.0](https://github.com/KapilXSam/Pharmalix-AI-2.0)** | Pharmalix AI product surface — TypeScript, React, Tailwind CSS |
| **[pharmalix-super](https://github.com/KapilXSam/pharmalix-super)** | Pharmalix platform build — TypeScript, React |
| **[Webhook-Automation](https://github.com/KapilXSam/Webhook-Automation)** | Event-driven automation service in TypeScript |
| **[UNO-JS](https://github.com/KapilXSam/UNO-JS)** | Browser card game, written from scratch in vanilla JS (HTML/CSS/JS, no framework) |
